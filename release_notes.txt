## Breaking Changes

- Now requires the 3DS:ATLAS module, which handles logging, update notices, and translations for this module.
- Raised the minimum Foundry VTT version to v14; verified compatible through 14.364.

## Changes

- Removed the standalone logging-level setting; log verbosity is now controlled centrally through 3DS:ATLAS.
