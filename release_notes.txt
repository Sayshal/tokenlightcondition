## Bug Fixes

- Calculate light levels only after Foundry rebuilds light sources, so creating a light or a batch of light, wall and token changes no longer leaves a token on its old level.
- On Pathfinder 2e, recreate a deleted Dim Lighting or Dark Lighting world item the next time a token needs it, instead of leaving the token with no effect.
- On Pathfinder 2e, stop deleting actor items named Dim or Dark that the module did not create.
- Stop the refresh-all API from warning players and non-primary GMs that the active scene is not drawn.
- Stop wall and tile changes from leaving pending refresh listeners behind.
